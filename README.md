# edu

수업 자료(교안 슬라이드, 수업지도안) 작업용 도구 모음입니다.

## 교안 편집기 — `editor.html`

Claude로 만든 교안·지도안 HTML을 브라우저에서 직접 고치고 HTML·PDF로 저장합니다.

- 설치 없이 파일 하나로 동작 (크롬·엣지 권장)
- 글자 바로 고치기, 발표자 노트·공통 정보(날짜·교시) 수정, 사진 바꾸기
- 원래 교안의 디자인과 기능(넘기기, 목차, 타이머, 발표자 창)을 그대로 유지한 채 저장
- 모든 슬라이드를 한 장에 한 페이지씩 PDF로 저장

사용법은 **[GUIDE.md](GUIDE.md)** 를 보세요.
